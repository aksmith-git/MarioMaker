# SMM2 Recomp on Windows

The Windows build (x64, Vulkan renderer) is being ported from the macOS one; this page gets its
requirements, build commands, the first-launch import and recompile from your own dump, and
troubleshooting as soon as it builds. Status per platform: [PROGRESS.md](../PROGRESS.md), "Recomp".

SMCraft's Windows build (`mmk-play.exe`) and its instructions are on the `smcraft-archive` branch.
